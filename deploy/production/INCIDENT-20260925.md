## 当前结论

故障在 Dify 调用模型服务的连接链路。模型配置为 OpenAI-API-compatible，`gpt-5.5`，Base URL `https://api.openai.com/v1`。服务器原本应有 `172.21.0.0/16 -> table 18080 -> 192.168.18.147` 的策略路由，但故障时规则和路由表均为空，尽管 `data-center-dify-egress.service` 显示 active (exited)。Dify 插件容器直接出网时 TLS 连接被重置；执行 `systemctl restart data-center-dify-egress.service` 后路由恢复，模型接口握手成功，真实问答恢复。

服务器时区为 CST。故障复现时间约 15:20、16:15 CST；恢复约 16:25 CST。重启出站服务时 Dify 容器及知识库后端短暂重启，之后均恢复健康。路由丢失的触发事件尚未确定。
